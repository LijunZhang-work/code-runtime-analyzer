# 新手从这里开始

如果你以前没用过这个工具，就按这篇做。先不要看“整体方案”“技术边界”等文档。

## 先明白它在做什么

普通日志分析的麻烦是：代码在 VS Code 里，历史数据在 CSV 里。你需要自己猜“这一列数据对应哪段代码”。

这个工具通过一份**字段字典**把两边连起来。连接成功后，你可以选择一个历史时间点，直接在代码旁查看当时的值。

## 先安装（只做一次）

1. 到 [GitHub Releases](https://github.com/LijunZhang-work/code-runtime-analyzer/releases/latest) 下载 `Code-Runtime-Analyzer-Setup-v*.exe`；
2. 双击安装并保留默认选项；
3. 安装程序会一起装好后台、Web、OpenCode MCP 和 VS Code 扩展；
4. 已经打开的 VS Code 重新加载一次窗口。

不要下载 GitHub 的 `Code → Download ZIP`。那是源码，普通用户不需要它；你也不需要安装 Node.js 或运行 npm。单独的 `.vsix` 只是扩展备用包，不是完整产品。

## 你需要准备什么

准备下面三样东西：

1. 一个 C/C++ 代码仓；
2. 一份适合这个产品的字段字典；
3. 一个装有本次日志 CSV 的文件夹。

如果你还没有字典，先看 [字段字典填写指南](字段字典填写说明.md)。仓库里的 `backend/dictionaries/2048-demo.csv` 可以作为例子。

## 第一次打开工具

1. 用 VS Code 打开 C/C++ 代码仓根目录，不要只打开某一个 `.cpp` 文件；
2. 在 VS Code 右侧找到“历史诊断”；
3. 如果右侧没有这个面板，确认已经安装并启用了 Code Runtime Analyzer 扩展；
4. 打开一个你想查看的 `.c`、`.cc`、`.cpp` 或头文件。

## 第一次加载数据

在右侧面板依次操作：

1. 点“选择字段字典”，选择当前产品；
2. 点“选择 CSV 文件夹”，选择本次导出日志所在的文件夹；
3. 点“加载 / 重新加载字典”；
4. 点“加载 / 重新加载 CSV”；
5. 点“选择回放时间”，选择一个时间点；
6. 点“开始展示”。

成功后，当前屏幕中能看见的 C/C++ 文件会出现历史值。鼠标放到对应代码上，还可以看到数据来源等信息。

## 为什么我点了却没显示

按下面顺序检查：

1. 是否已经点了“开始展示”；
2. 当前打开的是否是已保存的 C/C++ 文件；
3. 字典中的 CSV 文件名和真实文件名是否完全一样，包括大小写；
4. 字典中的列名和 CSV 第一行是否完全一样；
5. 字典中的定义文件路径是否能从代码仓根目录找到；
6. 工程是否生成了 `compile_commands.json`。

如果右侧面板出现红色错误，不要只看“失败”两个字。错误中通常会写明是哪份字典、第几行、缺哪个文件或列。

## 什么时候需要重新加载

- 换了一批 CSV：点“加载 / 重新加载 CSV”；
- 修改了字典：点“加载 / 重新加载字典”；
- 只是换了历史时间：直接重新选择时间，不需要重新解析代码；
- 暂时不想看历史值：点“结束展示”。

“结束展示”只会把代码旁的值隐藏，不会删除你的字典和 CSV。
